Source:
  IBM Plex Sans 1.1.0  https://github.com/IBM/plex/releases/tag/%40ibm%2Fplex-sans%401.1.0
  IBM Plex Mono 2.5.0  https://github.com/IBM/plex/releases/tag/%40ibm%2Fplex-mono%402.5.0

Changes:
  - Subset to U+0020-007E, U+00B7, U+2014, U+2026, U+2192, U+2212, U+2248, U+2713
    with fonttools pyftsubset, hinting removed.
  - Renamed, as the OFL requires for the Reserved Font Name "Plex": families
    "IBM Plex Sans" -> "Knot Sans" and "IBM Plex Mono" -> "Knot Mono" (name IDs
    1, 3, 4, 6, 16, 17). The IBM Plex trademark notice (name ID 7) was removed.
  - Copyright and licence records are unchanged.
